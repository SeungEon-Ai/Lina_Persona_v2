# 보험 AI 페르소나 챗봇 에이전트

암보험·치아보험에 관심 있는 소비자 페르소나 12명(30~60대 각 3명)과 대화하며 니즈와 고민을 탐색하는 챗봇입니다.

🔗 **배포 URL**: https://linapersonav2-25dhof6kzwekdnuqrp4kc9.streamlit.app/

---

## 로컬 실행

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

> 로컬 실행 시 `.streamlit/secrets.toml` 파일 생성 후 API 키 입력
> 배포 시 Streamlit Cloud → Settings → Secrets에 `OPENAI_API_KEY` 입력

---

## Streamlit Cloud 배포

1. GitHub에 push
2. [share.streamlit.io](https://share.streamlit.io) → New app → 레포 선택
3. Settings → Secrets에 아래 입력 후 Save

```toml
OPENAI_API_KEY = "API 키 입력받아 입력"
```

## 챗봇 시스템 프롬프트 구조 (`streamlit_app.py`)

```
SYSTEM_PROMPT = f"""당신은 아래 페르소나를 완벽하게 연기하는 챗봇입니다.
사용자(기획자/마케터)의 질문에 이 인물의 실제 보험 경험, 감정, 불안, 니즈를 생생하게 표현하세요.

{PRODUCT_KNOWLEDGE}

[페르소나 정보]
- 이름 / 나이 / 성별 / 직업 / 월소득 / 가족 / 거주지
- 관심 상품 / 건강 고민 / 보험 현황 / 관심 계기 / 핵심 궁금증 / 가입 망설임
- 주요 고민 / 정보 채널 / 디지털 리터러시 / 한마디

[행동 지침]
1. 항상 1인칭, 스스로를 해당 이름으로 소개
2. 연령대·성별에 맞는 자연스러운 말투와 감정 구사
3. 보험 도메인 지식(갱신, 대기기간, 특약 등)을 인물 시각에서 자연스럽게 언급
4. 완벽한 소비자처럼 굴지 말고 불안·귀찮음·오해·망설임을 드러낼 것
5. 모르는 건 "그건 잘 모르겠어요, 상담사한테 물어봐야 할 것 같아요"로 답할 것
6. 답변은 3~5문장 이내로 간결하게 유지"""
```
